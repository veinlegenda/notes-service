# Конфликт слияния

Где был конфликт: файл api-plan.md, третья строка (эндпоинт GET /notes).

Как получился: в ветке feature-search я изменил строку на "список всех заметок", а в ветке feature-tags на "список заметок с тегами". Сначала я слил в main ветку feature-search. При слиянии feature-tags Git не смог сам выбрать между двумя версиями одной строки и показал конфликт.

Как исправил: в редакторе GitHub (Resolve conflicts) вручную оставил одну строку, объединив обе правки: "список всех заметок с тегами", и удалил маркеры конфликта. Затем сделал отдельный коммит с исправлением (Commit merge) и завершил слияние.
